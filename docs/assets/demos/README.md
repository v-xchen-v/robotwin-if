# 六任务演示素材

六组 GIF / MP4 均取自当前正式结果中的成功回合，每组包含两个指令示例。
Attribute 使用 6 cm 大块与 4 cm 小块的 Big/Small 配对；Big 是 120 次中唯一成功例，不代表总体成功率。
视频只说明任务行为，不能代替完整成功率。

[sources.json](sources.json)记录模型、seed、指令、原始结果/视频相对路径与 SHA-256，以及裁剪、拼接、倍速与输出哈希。
原文件位于[下载包](../../download-results.md)的 `evaluation/`；示例均可按相对路径定位。
Sequence 为 3× 播放，Spatial 为 1.5×；其他示例为原速。面板较短的片段定格到较长片段结束。
