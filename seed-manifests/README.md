# 固定 seed 清单

已发布成绩使用 [20-blocks/](20-blocks/README.md)：六任务，每任务 20 个完整 blocks，每个模型 460 回合。

[200-blocks/](200-blocks/README.md) 是 2026-11-20 生成的扩展清单：每任务保留原 20 blocks，
追加 180 个 expert-qualified blocks，共 4,600 回合。该清单尚无对应的 policy 评测成绩。

[100-blocks/](100-blocks/README.md) 从 200-block 清单逐任务取前 100 个完整 blocks，
每个 mode 100 回合，每模型共 2,300 回合；包含独立 suite、seed/mode 映射及来源校验记录。
