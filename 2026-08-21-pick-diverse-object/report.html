TL;DR

做了什么

在 RoboTwin 2.0 上新建一个「颜色+名词 grounding」IF 任务：12 品类池采 4 个、指令点名 1 个、单臂拿起。含 oracle 专家演示 + 评测 harness。

怎么验证

Layer A（指令路由，纯 python 9/9）+ Layer B（判定正反例，仿真 16/16）+ collect_data→reporter 全流程跑通。

结论

核心 IF 诊断成立（位置随机、判定 target-specific）；12 品类等概率目标；瓶子 50/50 站/躺。oracle 成功率 82.8%。

最大的坑

「颜色最干净的变体未必能抓」；「站立瓶子」一度误判做不到，参考原生 pick_dual_bottles 才解决。

背景与目标

RoboTwin-IF 基准诊断 VLA policy 是否真按语言指令控制动作，而非退化成「看图选默认动作」。Pick-Diverse-Object 专测 target-object grounding：场景里 4 个物体，指令用「颜色+名词」（如 "the blue cup"）点名 1 个，其余 3 个是真实可抓的干扰项——policy 必须读懂指令才能选对。

论文（§6.2.1）只说「12 物品池采 4、颜色+名词点名、3 干扰、单臂、测 grounding」，没给具体 12 个物体、颜色词表、成功判据。这些都是本项目自建并显式标注「非论文确认」。

证据：眼见为实

以下视频是 collect_data 采集出的 oracle 专家演示（aloha-agilex），随 notes 目录离线可放。

颜色 grounding：目标「green cup」，场景里另有一个异色 cup 当干扰——光靠名词分不清，必须读颜色才能选对。这正是本 task 要考的点。
瓶子拿取：目标 green bottle。瓶子 50/50 站立/躺放——站立用 [0.66,0.66,-0.25,-0.25]（参考 pick_dual_bottles）+ 世界系抬起。
颜色 grounding：目标「red shoe」，干扰含另一只异色 shoe——同样逼读颜色。
基本拾取：目标 blue cup，干扰为 hamburg/can/mouse（4 个不同名词，名词即可辨——多数 episode 是这种）。
12 品类 / 16 变体池（SAPIEN 真实贴图 3D 快照）。颜色全部人眼核校锁定——native 描述里的颜色词是 MLLM 文本、有噪，不可信，最终以贴图为准。
站立瓶子的破解：带 scale 渲染后看清——[0.66,0.66,-0.25,-0.25]（右三格）让高瘦瓶子真·直立站住，而我最初试的 qpos 会倒。左一是躺放（端面朝外）。

关键决策 / 教训

  • 指令颜色+名词 = 字面量注入：{A}="the blue cup"（不含 /）走 native 的字面替换分支，而非随机物体描述——因为随机描述不保证含颜色、不保证能区分目标。
  • 采样策略 churn 三版（诚实记）：option A（强制颜色必要，但分布偏斜）→ option B（均匀，但目标仅 3 类）→ 12 品类等概率目标。根因是实现前没把「分布均匀」和「颜色 grounding 强度」这对张力想清楚，走了两轮返工。
  • 目标用 seed % 12 而非 rng 抽取：default_rng(seed).integers 对低连续 seed 聚簇（seed 0/2/3/4/8/10 全 → shoe/red），小规模采集直接偏斜。seed%N 又轻又对。
  • 「颜色最干净」≠「能抓」≠「放得住」：最蓝的 021_cup/base8 没有抓取标注、grasp 失败——三个信号（stable / 有 mesh / 有抓取标注）要分别核查。
  • 站立瓶子：别轻易下「asset 做不到」的结论。一度误判高瓶站不住，用户提示参考 pick_dual_bottles，去查发现正解 qpos + 世界系抬起（move_axis="arm" 对侧抓无效，会平移不升起）。

这份 report 不证明什么（诚实声明）：
  • 82.8% 是 oracle 脚本专家的成功率，不是任何训练过的 VLA policy——不代表某个模型 grounding 能力好。
  • 只 24-episode 小样本，每物体真实成功率有噪。
  • 该成功率混了场景稳定性（~17% 是瓶子/mug 翻倒，非 grounding），完美 grounding 也超不过 ~83%。
  • 颜色维度目前基本没压力——一个「色盲但懂名词」的 policy 仍能拿高分（见颜色 grounding TODO）。
  • 判定阈值 0.02 / 各物体抓取参数类推自原生任务，论文未确认。

怎么复现

# 1. 桥接（把 task 文件 symlink 进 submodule）
bash bridge_tasks.sh

# 2. Layer A（纯 python，秒级）
conda run -n RoboTwin python tests/pick_diverse_object/test_instructions.py      # → 9/9

# 3. Layer B（仿真，~10 分钟）
conda run -n RoboTwin python tests/pick_diverse_object/test_check_success.py     # → 16/16

# 4. 数据采集 + 成功率报告
cd third_party/robotwin && python script/collect_data.py pick_diverse_object pdo_bench
cd - && python tools/report_pick_diverse_object.py --collection \
    third_party/robotwin/data/pick_diverse_object/pdo_bench

# 渲染 12 物体池快照（颜色核校证据）
conda run -n RoboTwin python tools/render_pick_pool_snapshots.py
